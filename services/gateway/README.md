# Gateway

Единая публичная точка входа на порту 8080. Python 3.13.15, FastAPI, HTTPX.
Своей БД нет. Gateway вызывает Flight, Ticket и Bonus по HTTP; исходники
и модели доменных сервисов не импортируются.

## Запуск

Локально с уже запущенными сервисами:

```bash
uv sync --frozen --all-packages
uv run --package gateway python -m gateway.main
```

Настройки GATEWAY_HOST, GATEWAY_PORT, GATEWAY_FLIGHT_URL, GATEWAY_TICKET_URL,
GATEWAY_BONUS_URL читаются из окружения или .env. По умолчанию localhost
и порты 8060/8070/8050. В Compose используются имена контейнеров.

Полная система:

```bash
docker compose up --build -d --wait
```

При ранее обнаруженной проблеме DNS сборки Docker на Linux:

```bash
BONUS_BUILD_NETWORK=host TICKET_BUILD_NETWORK=host FLIGHT_BUILD_NETWORK=host GATEWAY_BUILD_NETWORK=host docker compose up --build -d --wait
```

Swagger: http://localhost:8080/docs. Health: /manage/health.
Health Gateway отражает готовность его HTTP-приложения. Состояние зависимых
сервисов проверяется их собственными healthcheck и обработкой запросов.

## API

| Метод | Маршрут |
|---|---|
| GET | /api/v1/flights?page=1&size=10 |
| GET | /api/v1/me |
| GET | /api/v1/tickets |
| GET | /api/v1/tickets/{ticketUid} |
| POST | /api/v1/tickets |
| DELETE | /api/v1/tickets/{ticketUid} |
| GET | /api/v1/privilege |

Кроме flights и health нужен X-User-Name. Ошибки валидации — 400,
чужой/отсутствующий билет — 404, зависимый сервис недоступен — 503.
Покупка возвращает 200, возврат — 204 без тела.
Тело покупки: {"flightNumber":"AFL031","price":1500,"paidFromBalance":false}.
Рейс должен существовать, цена должна совпадать с актуальной.
Список включает отмененные билеты. Gateway добавляет аэропорты и дату,
сохраняя цену купленного билета. /me включает короткий счет без истории.

## Покупка, возврат и сбои

Порядок покупки: проверить Flight → создать Ticket → применить Bonus.
Один UUID обозначает все внутренние действия покупки.
HTTP-клиенты повторяют внутренние GET/PUT при сетевых ошибках и ответах 5xx
(по умолчанию два повтора). Изменяющие запросы сохраняют UUID и тело.
Публичный POST не идемпотентен: новая покупка создает новый UUID.

При неизвестном результате покупки Gateway пытается отменить билет и обратить
бонусную операцию. Компенсация также вызывается после отмены задачи покупки.
Неуспешные компенсации повторяются в фоне раз в секунду, пока процесс работает.
Отмена билета предшествует компенсации Bonus, чтобы прекратить его использование.

Возврат: проверить владельца → обратить Bonus → отменить Ticket.
Если отмена Ticket не удалась, повтор DELETE завершает ее без повторного изменения
баланса. Отмененные билеты также проходят сверку Bonus при повторном DELETE;
обратная бонусная операция идемпотентна. Отсутствующая бонусная операция допустима
для уже отмененного билета, например после компенсации несостоявшейся покупки.

Общей транзакции между сервисами нет. Очередь компенсаций находится в памяти:
после падения Gateway автоматическое восстановление покупки не гарантируется.
503 может сопровождаться частично выполненной операцией. Не следует автоматически
повторять публичный POST. Для устойчивого восстановления нужен постоянный журнал
координации; он не реализован на этом этапе. Неизвестные результаты сетевых запросов
и запросы, еще обрабатываемые удаленным сервисом, не дают гарантии мгновенного отката.

HTTPX-клиенты переиспользуются и закрываются через lifespan приложения.
X-User-Name передается в каждом запросе отдельно. Ответы валидируются Pydantic.
GATEWAY_CONNECT_TIMEOUT/READ_TIMEOUT/WRITE_TIMEOUT/POOL_TIMEOUT:
по умолчанию 2/5/5/2 секунды; GATEWAY_RETRIES — 2.
Read timeout ограничивает ожидание очередной порции ответа, а не всю операцию.

## Проверки

Семь unit-тестов: покупка/агрегация, валидация рейса и цены,
бонусная оплата и завершение частичного возврата, владелец, компенсация после
неизвестного результата, повторы HTTP с тем же UUID и изоляцией заголовков,
отклонение неверного ответа сервиса.

```bash
uv run --all-packages pytest services/gateway/tests
uv run --all-packages pytest
uv run --all-packages mypy
uv run --all-packages ruff check services
uv run --all-packages ruff format --check services
newman run v1/postman/collection.json -e v1/postman/environment.json
```
